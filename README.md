## About me

I'm a **full-stack and mobile developer** based in **Cotonou, Bénin**. Since January 2025 I've been working remotely with clients in France, Belgium and West Africa under my studio brand **Deux Points**.

Most of my work sits between a Flutter app, the API behind it, and the automations that glue the business together. I like projects where the app has to keep working offline, where the data model matters, and where an AI feature actually saves someone time.

- 📱 **Mobile** : Flutter apps from first screen to App Store release
- 🛠️ **Backend** : Laravel, Symfony, Node.js, FastAPI, REST APIs
- 🌐 **Web** : React, Angular, Next.js
- 🤖 **AI & automation** : OpenAI integrations, Make, Zapier, Twilio
- 🤝 **Clients** : W-Technologies (France), Evee Engineering (Côte d'Ivoire), freelance missions on ComeUp
- 📍 Based in **Cotonou, Bénin 🇧🇯** · working on European hours

## Projects

**✨ SpiritVerse : Mobile app for W-Technologies (France)**
> Flutter · Laravel · Live on the App Store

Built and maintained the mobile app and its Laravel API for a French client, from feature work to store releases.

**🚌 Grand Voyageur : Fleet management (Côte d'Ivoire)**
> Flutter · Firebase · with Evee Engineering

Mobile app for managing a transport fleet: vehicles, trips and real-time data synced through Firebase.

**💊 PharmaGarde : On-duty pharmacy finder**
> Flutter · Laravel · Offline-first

Helps users find the pharmacy on duty near them, even with a weak or missing connection.

**🛒 AMAZONEBIZ : Multi-vendor marketplace**
> Flutter · Laravel · React · Node.js

Marketplace with vendor shops, mobile app and web back-office.

**🎯 Trouve-Moi : Leisure matchmaking platform (France)**
> Symfony · Angular · PostgreSQL · Elasticsearch · Docker

Collaborative project connecting people around leisure activities, with full-text search on Elasticsearch.
